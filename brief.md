# Romantic Private Love Story Website Brief

## Objective
Create a standalone, production-quality frontend mockup for a private romantic love story website designed for exactly three registered users: one Admin owner and two invited users. The page should feel like a luxurious, emotional, private digital love diary.

## Output Path
`C:\Users\HP\Desktop\موقع ويب\mockups\love_story_site`

The implementation should be self-contained and work by opening `index.html` directly in a browser. Use only local files. Do not reference external CDNs or external image services.

## Audience
A couple/private trio of authorized users who want a memorable romantic website for photos, memories, letters, music, goals, and guestbook messages.

## Aesthetic Direction
Romantic luxury with a cinematic, magical atmosphere. Use soft glassmorphism cards, dark purple-to-rose gradients, warm lavender glows, gold accents, floating hearts, falling rose petals, animated photo frames, rounded corners, and elegant transitions. The design should feel premium and intimate, not generic or overly cute.

## Color Palette
- Main: Soft Rose Pink `#FF7DAE`
- Secondary: Warm Lavender `#C9A0FF`
- Accent: Gold `#FFD700`
- Background: Dark purple to soft pink gradient
- Cards: translucent white glass with blur

## Typography Direction
Use local/CSS font stacks only. Pair an elegant high-contrast serif for headings with a clean modern sans-serif for interface text. Headings should feel romantic and editorial; body text should be readable on mobile.

## Content Structure
Build a polished single-page website with the following areas:

1. Secure Login Preview
- Show a premium login card for three private accounts.
- Include role pills for Admin, User 1, User 2.
- Communicate that only three accounts are allowed.

2. Hero Section
- Large romantic hero with generated CSS/raster-like abstract romantic background treatment.
- Centered love quote.
- Floating animated hearts.
- CTA button: `Our Story`.
- Include day/night mode toggle.

3. Love Timer Section
- Display Years, Months, Days, Hours, Minutes, Seconds.
- Implement real JavaScript countdown/count-up from a configurable relationship start date.
- Update every second.

4. Memory Gallery
- Beautiful responsive photo gallery using local gradient placeholders or generated local assets.
- Admin action UI for upload/edit/delete.
- Like buttons, favorite badges, lightbox image preview.
- Smooth transitions.

5. Love Story Timeline
- Events: First Meeting, First Conversation, First Date, Special Memories, Future Dreams.
- Each has date, description, and photo/visual.

6. Love Letters
- Romantic letters/messages.
- Admin can add unlimited letters in the UI concept.
- Include an animated envelope opening effect.

7. Music Section
- Background romantic music player UI with play/pause controls.
- Admin upload song action.
- Simulate fade effect visually/in JS. Do not require real audio files.

8. Daily Love Message
- Random romantic message displayed each day.
- Different message every 24 hours via date-based selection.

9. Future Goals Board
- Shared dreams/future plans with progress indicators.

10. Private Guestbook
- Only three users can write messages.
- Beautiful glass message cards with date/time.

11. Extra Romantic Features
- Floating heart particles.
- Falling rose petals animation.
- Smooth page transitions.
- Animated photo frames.
- Love percentage meter.
- Memory of the Day widget.
- Surprise button that shows a random romantic message.

12. Admin Dashboard Preview
- Manage users.
- Upload photos.
- Upload music.
- Edit timeline.
- Change timer start date.
- Manage quotes.
- Website analytics.
- Backup and restore data.

13. Footer
- Romantic quote.
- Relationship start date.
- Copyright.

## Interaction Requirements
- Love timer updates every second.
- Gallery lightbox opens/closes.
- Like buttons update counts.
- Surprise button changes message.
- Day/night mode changes mood while preserving palette.
- Music play/pause UI changes state.
- Envelope card animates open.
- Smooth anchor navigation from `Our Story`.

## Responsive Requirements
Must look carefully designed on desktop and mobile. Avoid tiny text, cramped cards, or horizontal overflow.

## Technical Requirements
- Create `index.html`, `styles.css`, and `script.js` in the output folder.
- Self-contained local implementation with no external dependencies.
- Use semantic HTML and accessible labels where appropriate.
- Include tasteful animations while respecting users with reduced-motion preferences.
- Use placeholder content and CSS-generated visual/photo cards where actual uploads would appear.

## Memorable Detail
The page should feel like entering a private moonlit rose garden made of glass: a glowing central love quote, drifting petals, luminous timeline, and intimate diary cards.
